# Pileus Ops website

The website for Pileus Ops, served at [pileusops.com](https://pileusops.com) by GitHub Pages.

The site is a single file, `index.html`, with no build step. Edit it, push to `main`, and the live site updates.

To preview locally, open `index.html` in a browser.

See `CLAUDE.md` for how the pages are organized and the brand and copy rules.
